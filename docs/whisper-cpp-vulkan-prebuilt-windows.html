babelscribe · GitHub

A prebuilt whisper.cpp Vulkan build for Windows

Short answer: skip the Vulkan SDK and CMake. pip install babelscribe fetches a prebuilt Vulkan whisper-cli for your system and runs it for you.

What it handles

  • Downloads a prebuilt whisper-cli (Windows / Linux Vulkan, Linux CUDA, macOS Metal, CPU) from this project's releases.
  • Converts any media to 16 kHz WAV with bundled ffmpeg; whisper.cpp itself only reads WAV.
  • Picks the discrete GPU over the integrated one (babelscribe devices, --device N).
  • Uses --max-context 0 so long files do not loop on one sentence.

Already have your own build? babelscribe talk.mp4 --bin /path/to/whisper-cli. Self-host the binaries with BABELSCRIBE_RELEASES.

pip install babelscribe
babelscribe devices
babelscribe talk.mp4

FAQ

Does whisper.cpp have a Windows Vulkan release?

The official releases do not ship a Windows Vulkan build. babelscribe publishes prebuilt Vulkan binaries and downloads the right one.

Do I need the Vulkan SDK?

No. You only need a GPU driver with Vulkan support, which AMD, Intel and NVIDIA drivers include.

Can I use my own whisper.cpp build?

Yes, pass --bin /path/to/whisper-cli.
