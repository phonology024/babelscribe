ทำซับไทยด้วย Claude Desktop ไม่ต้องพิมพ์คำสั่ง

คำตอบสั้นๆ: โหลด babelscribe.mcpb จากหน้า Releases บน GitHub แล้วดับเบิลคลิก จากนั้นพิมพ์ในแชทว่า “ทำซับไทยให้คลิปล่าสุดในโฟลเดอร์ดาวน์โหลด”

ขั้นตอน

  1. ดาวน์โหลด babelscribe.mcpb จาก GitHub Releases
  2. ดับเบิลคลิก หรือเปิด Claude Desktop → Settings → Extensions → Install extension
  3. พิมพ์ในแชท เช่น “ทำซับไทยให้คลิปล่าสุดใน Downloads” แล้ว Claude จะหาไฟล์ ถอดเสียงด้วยการ์ดจอของคุณ และบันทึก .srt ไว้ข้างไฟล์
  4. สั่งต่อได้ เช่น “ตรวจชื่อคนให้หน่อย” หรือ “แปลซับเป็นอังกฤษ”

ใช้ Claude Code ได้เหมือนกัน: claude mcp add babelscribe -- uvx babelscribe mcp ภาษาไทยให้เลือกโหมดแม่นยำสูง (Pathumma Whisper ของ NECTEC, CER 8.9% บน FLEURS) ดูรายละเอียดที่ ถอดเสียงภาษาไทย

คำถามที่พบบ่อย

ทำซับไทยด้วย Claude ได้ไหม

ได้ ติดตั้ง babelscribe เป็น MCP ใน Claude Desktop แล้วสั่งในแชท Claude จะถอดเสียงคลิปในเครื่องของคุณให้

ไฟล์วิดีโอถูกอัปโหลดไหม

ไม่ การถอดเสียงทำงานในเครื่องของคุณ ไม่มีการอัปโหลดไฟล์เสียงหรือวิดีโอ

ใช้ ChatGPT หรือ Grok บนเว็บได้ไหม

ไม่ได้ เพราะแอปเว็บเข้าถึงได้เฉพาะเซิร์ฟเวอร์บนอินเทอร์เน็ต ไม่ใช่คอมพิวเตอร์ของคุณ ให้ใช้ Claude Desktop, Claude Code, Codex CLI, Gemini CLI หรือ Cursor
