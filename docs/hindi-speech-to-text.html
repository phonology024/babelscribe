babelscribe · GitHub

Hindi speech-to-text and subtitles, free and offline

Short answer: babelscribe video.mp4 -l hi --accurate. Plain Whisper turbo misses a lot of Hindi; the community fine-tune used by --accurate brings it to 12.6% word error rate.

Accuracy on Google FLEURS (Hindi, 50 utterances)

SetupWER
Whisper large-v3-turbo (default)28.4%
--accurate: vasista22/whisper-hindi-large-v2 + turbo timing12.6%
--accurate, ignoring extra words at clip edges11.1%

The fine-tune is by vasista22 (Speech Lab, IIT Madras). Install the converter once with pip install "babelscribe[finetune]"; weights are converted on your machine, never redistributed.

pip install babelscribe
babelscribe lecture.mp4 -l hi --accurate -f srt,txt

FAQ

What is the best free Hindi speech-to-text?

On Google FLEURS, babelscribe --accurate with the vasista22 Hindi fine-tune reaches 12.6% WER versus 28.4% for plain Whisper turbo.

Does it work offline?

Yes. After the one-time model download everything runs on your computer.

Can I get Hindi subtitles for a video?

Yes, add -f srt to get a .srt file next to the video.
